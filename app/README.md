
# Harness CI/CD Demo

## Project Overview
A hands-on CI/CD project using Harness, GitHub and Docker.

## Technology Stack
- GitHub
- Harness CI/CD
- Docker
- Nginx

## Application
A simple HTML application served using Nginx.

## Pipeline Workflow
1. Fetch source code from GitHub.
2. Build Docker image.
3. Push image to Docker Hub.
4. Deploy application.

## Learning Objectives
- GitHub integration with Harness
- CI pipeline configuration
- Docker image building
- Automated image publishing
